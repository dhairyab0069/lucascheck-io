A database course project, rebuilt

A store you can check out of, and the tables behind it.

Lucas-Check is a mock sporting goods store. It began as the term project for COSC 304, Introduction to Database Systems: JSP pages on Tomcat over a SQL Server database. In 2026 it was rebuilt on Next.js 16 and Postgres so it can run on Vercel. This page keeps a small working copy of the store, draws its schema, and lines the two versions up.

    4 · About this page

    What is real here.

    The real thing

    The store itself is a Next.js 16 app with React Server Components, Server Actions, Tailwind 4, and Postgres through pg (or PGlite, Postgres in WebAssembly, for the no-setup demo). Sessions are a signed HTTP-only cookie; passwords are bcrypt hashes. Open the live demo, or read the code and the original course report.

    The miniature

    The store on this page is a separate, plain JavaScript re-implementation of the same rules over the same seed data, with no server, so the page can live on GitHub Pages. It is not the Next.js app, and with no payment step nothing is for sale. The sample accounts' passwords are public on purpose. Orders you place stay in this browser (local storage, when allowed) until you reset.

    The group

    Lucas-Check began as the COSC 304 term project of Group 4: Dhairya Bhatia, Jay Bhullar and Sumer Mann, with Khalid Mahmoud as instructor. The Next.js rebuild is Dhairya's. Product photos were collected by the group from retailers' public listings for the course project; brand names in the photos belong to their owners.
